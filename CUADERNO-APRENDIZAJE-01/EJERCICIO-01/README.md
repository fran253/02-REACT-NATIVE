# Ejercicio 01 - Mi primera pantalla

## Qué he aprendido
- A inicializar un proyecto mínimo en React Native usando Expo y TypeScript.
- A estructurar la jerarquía visual básica mediante contenedores y etiquetas de texto.
- A aplicar estilos personalizados con objetos JavaScript a través de `StyleSheet.create()`.

## Respuesta a la pregunta de comprensión
Explica con tus palabras la diferencia entre el componente `View` y el componente `Text`.

Respuesta:
View es un contenedor, un "div" de toda la vida, sirve para agrupar elementos, estructurar el diseño...
Text es un componente específico y obligatorio que se utiliza exclusivamente para mostrar cualquier cadena de texto en la pantalla

## Qué he modificado
- He añadido una línea adicional de texto con el curso escolar actual
- He cambiado la paleta de colores predeterminada de la guía por un fondo oscuro con tonos azules y blancos, y le he aplicado negrita al nuevo texto para darle más contraste.

## Resultado
La interfaz muestra una pantalla centrada en vertical y horizontal con un fondo oscuro, un título principal grande en blanco, un subtítulo gris y el texto del curso destacado en un tono cian brillante.
